# PTverse social-media delivery assets

This public repository hosts stable image URLs used by PTverse's social scheduler. It contains approved carousel exports only—no credentials, private source files, or patient data.

- 22 carousel posts
- 6 ordered slides per post
- `feed`: 1080×1350 for Instagram and Facebook
- `tiktok`: 1080×1920 with safe text margins

Clinical sources, captions, and ordered file paths are listed in `posts.json`. PTverse original artwork remains owned by PTverse. Where an approved carousel embeds third-party educational media, the source batch's attribution terms apply and embedded attribution must remain intact.
